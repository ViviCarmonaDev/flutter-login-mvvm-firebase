# Flutter Login MVVM + Firebase

Proyecto de práctica que implementa un flujo de inicio de sesión y registro usando
Firebase Authentication como backend, siguiendo el patrón de arquitectura MVVM
en Flutter/Dart.

Esta documentación explica:

- Cómo está organizada cada capa de la arquitectura y por qué.
- Cómo configurar tu propio proyecto de Firebase para correr la app.
- Cómo funciona el flujo de autenticación paso a paso.
- Las decisiones técnicas y diferencias frente a la versión en Kotlin/Android nativo.

> Para instrucciones rápidas de instalación, consulta el `README.md` en la raíz del
> repositorio de GitHub.

📱 Proyecto hermano en Android nativo (Kotlin): [android-login-mvvm-firebase](https://github.com/ViviCarmonaDev/android-login-mvvm-firebase)
